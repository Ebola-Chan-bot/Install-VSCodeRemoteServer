安装-VSCode远程服务 是一个 PowerShell 模块，用于通过 SSH 在远程主机上自动安装与本机 VS Code 版本严格匹配的 VS Code Server。它会自动检测远程系统类型（Windows / Linux），选择对应的安装方式，并在整个过程中复用一次输入的 SSH 密码，无需反复认证。

# 功能特性

- **自动系统检测**：通过 `uname` 判别远程是 Linux 还是 Windows，无需用户指定
- **Windows 支持**：使用 BITS 后台下载，按远程 PowerShell 版本自动选择通用版或 Win7 兼容版安装脚本
- **Linux 支持**：使用 sh 脚本直接下载安装，自动检测 x64 / arm64 / armhf 架构，支持 curl / wget，含备用下载源
- **版本严格匹配**：自动读取本机 VS Code 的提交号与发布通道（稳定版 / 预览版），下载与之完全对应的服务端
- **密码复用**：基于 `SSH_ASKPASS` 注入，全程只需输入一次密码；已配置密钥免密的主机则完全免交互

# 系统要求

- 本机：Windows PowerShell 5.1 或 PowerShell 7+，已安装 OpenSSH 客户端（`ssh` / `scp`）
- 远程 Windows：PowerShell 2.0+（Win7 兼容）或 3.0+（通用），启用 BITS
- 远程 Linux：`sh`（bash / dash / ash 均可），`curl` 或 `wget`，`tar`

# 使用方法

```powershell
安装-VSCode远程服务 -远程主机 192.168.1.100 -远程账户 user
```

常用参数：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-远程主机` | 目标主机名或 IP（必填，位置参数 0） | — |
| `-远程账户` | SSH 登录账户 | 当前用户名 |
| `-SSH端口` | SSH 端口 | `22` |
| `-本地版本` | `预览版` 或 `稳定版`，本机同时装有两个版本时必填 | 自动检测 |
| `-轮询秒数` | 下载进度轮询间隔（秒） | `3` |
| `-最大恢复次数` | 下载中断后的最大恢复次数 | `5` |
| `-超时秒数` | 下载超时时间（秒） | `600` |
| `-远程脚本版本` | `自动` / `通用` / `Win7`，仅 Windows 有效 | `自动` |

示例：

```powershell
# 指定端口与预览版
安装-VSCode远程服务 10.15.49.6 -SSH端口 22112 -本地版本 预览版 -远程账户 v-jiamh

# 强制使用 Win7 兼容脚本（仅 Windows 远程）
安装-VSCode远程服务 192.168.1.200 -远程脚本版本 Win7
```

# 工作原理

1. 读取本机 VS Code 的提交号与发布通道，确定要安装的服务端版本
2. 通过 SSH 探测远程主机是否已配置免密；若需密码则收集一次，后续经 `SSH_ASKPASS` 自动注入
3. 执行 `uname -s` 判别远程系统类型
4. Linux：上传 sh 安装脚本，远程自动检测架构、下载对应 tar.gz、解压并铺平目录
5. Windows：按远程 PowerShell 版本选择安装脚本（通用版走 BITS 直接下载，Win7 版由本机中转上传 zip），上传执行
6. 校验关键可执行文件（稳定版 `code-server` / 预览版 `code-server-insiders`），输出安装结果
