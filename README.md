通过 SSH 在远程主机上自动安装与本机 VS Code 版本严格匹配的 VS Code Server。它会自动检测远程系统类型（Windows / Linux），选择对应的安装方式。

# 功能特性

- **自动系统检测**：通过 `uname` 判别远程是 Linux 还是 Windows，无需用户指定
- **Windows 支持**：使用 HTTP 断点续传下载（基于 Range 头），按远程 PowerShell 版本自动选择通用版或 Win7 兼容版安装脚本
- **Linux 支持**：使用 sh 脚本直接下载安装，自动检测 x64 / arm64 / armhf 架构，支持 curl / wget，含备用下载源
- **版本严格匹配**：自动读取本机 VS Code 的提交号与发布通道（稳定版 / 预览版），下载与之完全对应的服务端

# 使用方法

```powershell
安装-VSCode远程服务 -远程主机 192.168.1.100 -远程账户 user
```

常用参数：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-远程主机` | 目标主机名或 IP（必填，位置参数 0） | — |
| `-远程账户` | SSH 登录账户 | 当前用户名 |
| `-SSH端口` | SSH 端口 | `22` |
| `-本地版本` | `预览版` 或 `稳定版`，本机同时装有两个版本时必填 | 自动检测 |

示例：

```powershell
# 指定端口与预览版
安装-VSCode远程服务 10.15.49.6 -SSH端口 22112 -本地版本 预览版 -远程账户 v-jiamh
```
